FalconPulsar is installed!

Open the Web UI:

http://localhost

Service URLs:

Web UI:      http://localhost
REST API:    http://localhost:7433
WebSocket:   ws://localhost:7434
AI Gateway:  http://localhost:7436

Manage the stack:

cd ~/falconpulsar
docker compose ps  — status
docker compose logs -f  — follow logs
docker compose restart  — restart
docker compose down  — stop

Data location:

Stack files: ~/falconpulsar/
Database: ~/falconpulsar/data/
AI Gateway data: ~/falconpulsar/ai-gateway-data/

Uninstall:

bash ~/falconpulsar/uninstall.sh
