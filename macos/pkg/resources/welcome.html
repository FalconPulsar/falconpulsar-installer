FalconPulsar

Version 0.1.0
Self-host in 3 minutes. Your infrastructure, your data.

This installer will set up:

  • Core engine (REST API + WebSocket) on port 7433
  • Web UI for dashboards and operations on port 80 (http://localhost)
  • AI Gateway for natural-language interaction on port 7436

Requirements:

  • macOS 14 Sonoma or newer
  • 8 GB RAM minimum
  • A container runtime: Docker Desktop, Colima, OrbStack, or Rancher Desktop

After the install:

Open http://localhost in your browser to access the Web UI.
