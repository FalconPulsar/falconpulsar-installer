# Code of Conduct

FalconPulsar is committed to providing a welcoming and respectful environment
for everyone who contributes to or interacts with this project, regardless of
experience level, background, or identity.

We expect all participants — maintainers, contributors, and users — to:

- Be respectful and constructive in discussions, code reviews, and issues
- Assume good faith and give others the benefit of the doubt
- Focus criticism on ideas and code, not on people
- Accept feedback gracefully and offer it kindly
- Help newcomers get started

The following behaviours are not acceptable in any FalconPulsar space
(issues, pull requests, discussions, email, chat):

- Personal attacks, insults, or derogatory comments
- Harassment of any form, public or private
- Publishing others' private information without their explicit permission
- Deliberate intimidation, stalking, or disruption of discussions
- Any conduct that a reasonable person would consider inappropriate in a
  professional setting

## Scope

This code of conduct applies to all project spaces — the GitHub repository,
pull requests, issues, discussions, and any official communication channel —
as well as to individuals representing the project in public.

## Enforcement

If you experience or witness behaviour that violates this code of conduct,
please report it by emailing **contact@falconpulsar.com**. All reports will be
reviewed and investigated promptly and confidentially.

Maintainers who fail to enforce this code of conduct in good faith may face
temporary or permanent repercussions as determined by other members of the
project's leadership.
